Two manuscripts

Papers. Not a standard, and not presented here as peer-reviewed.

Both are the work of Osita Sean Keluo-Udeke, as the licensing file states. A DOI means the manuscript is deposited. It does not mean a journal accepted it, and it does not mean a standards body adopted it.

Untrusted Text, Trusted Tokens

Bounding the authority of AI agents in software build pipelines. The manuscript states the agent controls R1 to R8. Those are requirements. A passing check is not a claim that every one of them is implemented and verified.

Repository copy. DOI 10.5281/zenodo.23622566.

Securing the Game Build

A sector profile of SSDF and SLSA, and a self-assessment model for independent studios. Game studios are the worked example. That is not a statement that a studio has deployed OBAAF. The crosswalk is a mapping. It is not a certification and not a SLSA level.

Repository copy. DOI 10.5281/zenodo.23622802.

The catalogue maps documented cases to controls that might matter. A mapping is not a test that a control would have prevented the case.
