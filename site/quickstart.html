A gate is a repository setting

The exit status does not configure a merge gate. A person can require a status check. That is a setting in the repository, and this page did not create one. A local exit is not a hosted run. Prepared YAML is not a workflow that GitHub executed.

There is no obaaf init in release 0.3.0, and this page does not invent one. Companion scanners are named on the comparison page. Setting them up is separate work.
